Bank Account Management System Using Spring Boot

📌 Project Overview

The Bank Account Management System is a backend application developed using Java and Spring Boot. It provides REST APIs to manage bank account operations and perform basic banking transactions.
The application integrates MySQL as its database to store and manage account-related information.
This project demonstrates the practical implementation of Spring Boot concepts, RESTful web services, database connectivity, and layered architecture.

🚀 Features
Account Management: Manage bank account information.
Deposit Money: Add money to a bank account.
Withdraw Money: Withdraw money from an account.
Money Transfer: Transfer money between bank accounts.
REST APIs: Perform banking operations through RESTful endpoints.
MySQL Integration: Store and manage application data using MySQL.
